FIRESTICK-WII — ONE REPOSITORY / WINDOWS 10

1. Connect the Fire Stick's HDMI output to a TV/monitor.
   The PC's Micro-USB may power the Stick but may not enable ADB.
   The MT65xx Preloader driver does NOT replace Android ADB.
2. Ensure it boots, and enable/authorize ADB using an alternate
   remote method (TV HDMI-CEC, Fire TV phone app, or OTG input).
3. Ensure adb and git are on PATH. For compiling the launcher, install
   JDK 17+ and Android SDK Platform 34 / Build-tools 34.0.0.
4. Double-click run.bat (USB ADB), or from PowerShell run:

   powershell -ExecutionPolicy Bypass -File .\setup.ps1 -FireTvIp 192.168.1.50

   Replace 192.168.1.50 with the Stick's local IP address.
5. Follow prompts to test TV Bro, install AirScreen from Amazon Appstore
   and test both phones, and test the Wii launcher.
6. Optional: approve a reversible debloat plan after reading it.
7. HOME replacement may be blocked by Fire OS. Try only after tests:
   powershell -File .\scripts\activate-home.ps1 -FireTvIp YOUR_IP
8. Restore only our recorded changes:
   powershell -File .\scripts\restore.ps1 -FireTvIp YOUR_IP

Before uploading this to GitHub as your SINGLE source repository:
   powershell -ExecutionPolicy Bypass -File .\scripts\get-sources.ps1
   git init
   git add .
   git commit -m "Initial firestick-wii"
Then add your GitHub remote and push. third_party/ now includes upstream
wii-tv + dumbtv MIT-licensed source and required notices.

The ZIP does not contain third-party APK binaries or upstream source trees
until the get-sources script is run. This integration toolkit has not been
tested on your actual Stick. See README.md for details and safety rules.
